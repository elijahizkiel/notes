# Portfolio Blog

This repository contains the blog posts published on my portfolio. It serves as the source for sharing technical notes, tutorials, and articles about software development, tools, and technologies I work with.

Each Markdown file represents a blog post and includes front matter metadata such as its title, description, publication date, category, tags, publication status, and related projects. The content is organized by topic so it can be maintained and published as part of my portfolio.

## Purpose

The repository is used to:

- Write and maintain blog posts in Markdown.
- Publish technical articles on my portfolio.
- Keep article metadata consistent across posts.
- Document projects, workflows, and development experience.

The articles are intended to be practical, readable references that reflect my work and interests as a developer.
